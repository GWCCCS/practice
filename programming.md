## Minimum Level of Experience - Java **II**/Object Oriented Programming & Some Github (See [Other Skills](otherskills.md))
These can be done independently or collaboratively. Sometimes I or another student will have a solution committed under a different branch.
- [ ] Astound - "Boggle" inspired game (As a graphical interface) - [repo](https://github.com/GWCCCS/astound) - [discussion](https://discord.com/channels/1175834061500067840/1240378764710510653)
    - ref: https://en.wikipedia.org/wiki/Boggle
- [ ] Tribot - Triangle Building "Robot"- [repo](https://github.com/GWCCCS/tribot) - [discussion](https://discord.com/channels/1175834061500067840/1240379482544668742) - [project](https://github.com/orgs/GWCCCS/projects/5) - Larger project to give experience with project based development
    - The "robot" is a simulation of a real robot that builds a triangle using pieces taken from either the table or a bag. The steps the robot follows are based on an ordered list of instructions (algorithm) written by the user. The instructions are limited to basic vocabulary that is understood.
- [ ] CourseData - CS Course Data Analysis Tool- [repo]() - [discussion](https://discord.com/channels/1175834061500067840/1240379894005760051) - [project](https://github.com/orgs/GWCCCS/projects/6) - Larger project with Data focus
    - The tool will build a data set of courses with topics, learning outcomes, and prerequisites.  The data set will also have a set of programs/majors that contain courses.  The tool will help describe what skills are part of what program and what the shortest path for a student to complete a program would be.
- [ ] Golf Score Project- [repo]()- [discussion](https://discord.com/channels/1175834061500067840/1240379978277982228) - [project](https://github.com/orgs/GWCCCS/projects/4?pane=info) - Medium Sized project with real world problem
    - Golf requires a mathematical analysis of scores to compute a "handicap".  This tool will read in score data from a file and create a new file with a "handicap".
